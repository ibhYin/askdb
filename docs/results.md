### 观察

1. **失败集中在"多返回列"**：问"哪些城市"返回城市 + 计数；问"占比"返回占比 + 订单数。
   SQL 语法和逻辑都对，错在没遵守"只回答问题所问"。
2. **同题两次结果不同**：q021 在 run 1 错、run 2 对，温度已是 0。
   服务端非确定性 → 单次分数是噪声，正式结论要跑 k 次取均值。
3. **样例集已饱和**：95.8% 意味着这套题量不出改进了，必须换 BIRD 100 题。
